# 料金見積

画像解析APIの月額コスト見積。リクエスト規模別に算出。

## 前提条件

- リージョン: ap-northeast-1（東京）
- 料金は2026年3月時点のAWS公式料金に基づく（税別・USD）
- 1リクエストあたりの画像: 1枚
- Lambda実行時間: 平均5秒（OpenAI API呼び出し含む）

## リソース構成

| リソース | 仕様 | 根拠 |
|---------|------|------|
| API Gateway | REST API, Regional | api/template.yaml |
| Lambda | Python 3.12, 512MB, タイムアウト60秒 | api/template.yaml |
| Cognito | User Pool（管理者作成のみ） | api/template.yaml |
| S3 | Standard, SSE-AES256 | web/template.yaml |
| CloudFront | PriceClass_200, HTTP/2+3 | web/template.yaml |
| CloudFront Function | IP制限 + パスリライト | web/template.yaml |
| Route53 | Aレコード（エイリアス） | web/template.yaml |
| ACM | SSL証明書（us-east-1） | web/template.yaml |
| SSM Parameter Store | OpenAI APIキー（1パラメータ） | api/template.yaml |

#### Lambda実行時間の計算根拠

```
メモリ: 512MB = 0.5GB
実行時間: 平均5秒/リクエスト
GB秒単価: $0.0000083334

10,000件の場合:
0.5GB × 5秒 × 10,000件 = 25,000 GB秒
25,000 × $0.0000083334 = $0.21
（無料枠 400,000 GB秒/月を超えない限り実質無料）
```

## コスト構造の特徴

1. **OpenAI APIが支配的**: AWSインフラコストは月額$1未満。コストの大半はOpenAI API利用料
2. **モデル選択が最大の変動要因**: gpt-4.1はgpt-4.1-miniの約5倍のコスト
3. **detail設定の影響**: detail=highは画像トークンが約10倍になるが、出力コストは変わらない
4. **AWS無料枠**: Lambda（100万リクエスト/月、400,000 GB秒/月）の範囲内であれば実行コストはほぼゼロ
5. **Cognito**: 50,000 MAU以下は無料。本システムの想定利用者数では課金対象外

## 注意事項

- 上記はリクエスト処理のみのコスト。データ転送量（CloudFront → クライアント）は含まない
- OpenAI APIの料金は変更される可能性がある
- Lambda無料枠はAWSアカウント全体で共有。他サービスとの共用時は枠を超える可能性あり
- 為替レート（USD/JPY）の変動により円建てコストは変動する
