# 料金見積

画像解析APIの月額コスト見積。単一画像解析に加え、画像比較（災害差分監視）の監視シナリオを掲載する。AI推論は Amazon Bedrock Claude、Amazon Bedrock GPT、Claude Platform on AWS（CPoA）の3プラットフォームから選択できる。

## 前提条件

- 既定モデルは Amazon Bedrock Claude の `anthropic.claude-sonnet-5`。入力／出力単価は CPoA の `claude-sonnet-5` と同一のため、既定モデルをBedrockへ変更してもAI推論コストの試算は従来と同額
- モデルIDの名前空間により、`anthropic.claude-*` は Bedrock Claude、`openai.gpt-*` は Bedrock GPT、プレフィックスなしの `claude-*` は CPoA を使用する
- Bedrock Claude は Haiku 4.5 / Opus 4.7 / Opus 4.8 を東京、Sonnet 5 を米国東部で処理する。Bedrock GPT は米国東部（Ohio）で処理する
- 料金は税別USDで記載し、円換算は為替 `155円/USD` を使用する
- 1リクエストあたりの画像は、単一解析=1枚、画像比較=2枚（前回・今回）
- Lambda実行時間は単一解析=平均5秒、画像比較=平均10秒（画像2枚・AI呼び出し含む）としてAWS側の概算を算出する

## コスト構造の特徴

1. **AI推論利用料が支配的**: AWSインフラコストは小さく、監視コストの大半は選択したモデルと監視回数で決まる
2. **モデル選択が最大の変動要因**: 低コストのGPT-5.6 Luna / Claude Haiku 4.5 と高性能モデルでは月額差が大きい
3. **既定モデルのBedrock移行は単価同額**: Bedrock Sonnet 5 とCPoA Sonnet 5は同じ単価のため、既定変更によるAI推論コスト増はない
4. **Sonnet 5の価格切替**: 2026-09-01以降、Sonnet 5は入力$3／出力$15となる。切替後の試算は表の併記値を使用する
5. **effort設定の影響**: 対応モデルで effort を上げると推論トークンが増加し得るため、実コストは上表を上回る場合がある
6. **AWS無料枠**: Lambda（100万リクエスト/月、400,000 GB秒/月）の範囲内であれば実行コストはほぼゼロ

## 注意事項

- 上記はリクエスト処理のみのコストであり、データ転送量（CloudFront → クライアント）は含まない
- AIモデルおよびAWSの料金は変更される可能性がある
- 円換算は155円/USDの固定値による概算で、実際の請求額は為替レートにより変動する
- Lambda無料枠はAWSアカウント全体で共有する。他サービスとの共用時は枠を超える可能性がある
